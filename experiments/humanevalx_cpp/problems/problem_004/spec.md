# problem_004: reverse_string

文字列 `s` を受け取り、文字の並びを逆順にした文字列を返す関数 `reverse_string` を実装する。

## シグネチャ

```cpp
std::string reverse_string(std::string s);
```

## 入力

- `s`: `std::string`

## 出力

- `s` の文字順を逆にした `std::string` を返す。

## 例

- `reverse_string("abc")` は `"cba"` を返す。
- `reverse_string("")` は `""` を返す。
