## 設計書 – `is_even` 関数

| 項目 | 内容 |
|------|------|
| **関数名** | `is_even` |
| **C++ の関数シグネチャ** | ```cpp<br>bool is_even(int n)<br>``` |
| **引数名と型** | `n` : `int` – 判定対象の整数。負数・0 も含む。 |
| **返り値の型と意味** | `bool` – `true` の場合は `n` が偶数（2で割り切れる）を示し、`false` は奇数を示す。 |
| **処理内容** | 1. 引数 `n` を 2 で割った余りを計算する (`n % 2`)。<br>2. その余りが 0 かどうかを比較し、結果（真偽値）を返す。 |
| **境界条件** | - `n = 0` → 偶数として `true` を返す。<br>- 負の整数も正しく判定できる（C++ の `%` 演算子は負数でも余りが 0 になると偶数とみなされる）。<br>- `int` の最大・最小値に対してもオーバーフローは起きない。 |
| **想定される計算量** | 時間: **O(1)**（定数時間）<br>空間: **O(1)**（追加メモリ不要） |

---

### 補足
- この関数は副作用を持たず、入力に対して純粋な結果を返すため、テストや再利用が容易です。  
- 余り演算子 `%` は整数型同士の除算で残りを返すので、負数でも正しく偶奇判定が行えます。
